## Overview

Wikyslavery is a net art installation that automates misleading edits to unspecified Wikipedia articles. It treats Wikipedia as infrastructure and as a cultural symbol. Real-time processes keep altered text in circulation long enough that Wikipedia’s social machinery shows: patrol workflows, revert speed, and the unpaid attention that holds the encyclopaedia together.

The piece occupies time that would otherwise go to ordinary maintenance, and makes that cost explicit. It also asks what counts as a stable source when content can be automated, and who pays when it is not.

## How it works

Algorithms run continuously, selecting targets and mutating text that is coherent enough to pass a quick scan, then still triggers correction. Wikipedia is framed as a public record and as training data for large models. If machine learning systems ingest the open web, small distributed distortions can look authoritative because of the channel they arrive through, while still costing human editors time.

The title joins wiki and slavery on purpose. It names a loop where human attention is extracted to repair what machines and scripts break open.

The software has to run for the length of an exhibition. Some material is never shown.

## Context
